# One-off measurements from the axion_ns migration (archived 2026-11-21)

Manual scripts that compared the modular `axion_ns/` with the original package or between integrator settings. Their results are recorded in
`axion_ns/MIGRATION.md`; they are kept for reference only and are not maintained. They were written to run from `axion_ns/tests/` (they set
`sys.path` from their own location), so they need path edits to run from here, and `compare_s1_logp.py` predates the 2026-11-20 S1 shooting change.
